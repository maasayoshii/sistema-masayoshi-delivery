# 🍣 Sistema de PDV - Masayoshi Delivery

Sistema web de Ponto de Venda (PDV) e gerenciamento de pedidos desenvolvido exclusivamente para otimizar a operação real do Masayoshi Delivery. 

Criar uma solução do zero foi a maneira que encontrei de aplicar os conhecimentos de Ciência da Computação para resolver os gargalos de atendimento do nosso próprio negócio, substituindo planilhas e chats genéricos por uma ferramenta rápida, segura e automatizada.

## 🚀 Funcionalidades

- **Carrinho Dinâmico:** Adição de itens, controle de quantidade e observações customizadas.
- **Integração ViaCEP:** Busca automática de endereço e cálculo dinâmico de taxa de entrega baseado no raio de distância do restaurante.
- **Tela de Checkout:** Revisão do pedido com aplicação de descontos, acréscimos e cálculo automático de troco (para pagamentos em dinheiro).
- **Banco de Dados em Tempo Real:** Autenticação restrita de funcionários e armazenamento de histórico de clientes/pedidos na nuvem utilizando **Firebase**.
- **Impressão Térmica:** Layout CSS otimizado especificamente para impressoras térmicas não fiscais de 76mm.

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript (Vanilla)
- **Back-end / BaaS:** Firebase (Auth, Firestore Database)
- **APIs Externas:** ViaCEP
